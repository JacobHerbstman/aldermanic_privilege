# Main Density Results

This task estimates the paper's 100ft distance-bin specification for FAR and
DUPAC and produces the main figure, its underlying estimates, and the sample
summary. All outputs use the generated project file from
`tasks/new_construction_analysis_data` and classify boundary sides with the
current through-2022 alderman score produced by the paper pipeline.

Each outcome uses its own eligibility flag and positive, finite density. The main sample summary reports the FAR and homes-per-acre samples separately; sample sizes are computed from the models, not fixed to the old paper counts.
