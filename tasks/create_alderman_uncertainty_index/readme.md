# Alderman Stringency Scores

This task estimates the alderman stringency scores used throughout the paper.

The first-stage permit regression includes median household income but omits
bachelor's-degree share. It also includes the demographic, geographic,
workload, permit-type, review-type, and month controls described in the paper.

It writes the December 2022 score file and first-stage table, as well as the
pre-redistricting score estimated using permits filed through 2014 for the
permit event study.
