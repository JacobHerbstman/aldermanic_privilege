# Permit Event-Study Balance

This task compares pre-redistricting permit activity and neighborhood
characteristics between blocks that changed wards in 2015 and nearby blocks
that did not. The sample uses stable-incumbent ward pairs represented in both
groups and requires at least one high-discretion permit during 2010--2014.
Standard errors are clustered by ward pair.

The paper uses `output/permit_itt_balance_500ft.tex`.
