# Second City Zoning district summary

Second City Zoning's table of Chicago's 67 zoning district types, with each district's title, code section, floor
area ratio, height, lot area per unit and setbacks (DataMade and Juan-Pablo Velez,
https://secondcityzoning.org/resources/import/zoning-code-summary-district-types.csv). Retrieved September 27, 2026;
`code/zoning-code-summary-district-types.sha256` records that vintage, and the download fails if the published file
has changed. Run `make` in `code/`. This is the same file as the untracked copy previously kept in `data_raw/`.
