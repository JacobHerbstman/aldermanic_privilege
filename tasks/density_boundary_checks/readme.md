# Density Boundary Checks

This task produces the density appendix tables. One table reports the main estimates
after restricting the sample to projects near straight boundary segments or boundaries
with limited overlap with physical features and major arterials. The second tests
whether four fixed location characteristics change at the ward boundary.

Both tables use the same 100-foot distance-bin specification and common FAR-DUPAC
samples as the main density figure. Standard errors are clustered by ward pair.
