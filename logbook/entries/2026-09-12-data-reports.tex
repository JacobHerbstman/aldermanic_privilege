\textit{September 12, 2026. Agent-drafted record of the reporting cleanup.}

build. Forty-nine task Makefiles no longer name \texttt{.log} files. R producers
write the same datasets, with the same formats and row order, and describe them
when saving. Deleting a dataset invokes its producer; deleting only its report
does not recalculate the data. This follows Jacob's requested use of
\texttt{SaveData} and supersedes the earlier missing-report recovery checks.

recorded sources; only reviewed decisions should become fixed correction inputs.

Deliberate acquisition writes separate current responses for comparison; it
